# Interactive Coffee Sales Dashboard

A practice project completed by following a guided Excel tutorial. The project uses coffee sales data from three countries and combines information from multiple reports to create an interactive sales dashboard.

## What I Did

* Combined data from multiple reports using Excel functions
* Used XLOOKUP and INDEX/MATCH to connect information across datasets
* Applied IF functions and sales calculations
* Checked for duplicates and organized the data into an Excel Table
* Created PivotTables and PivotCharts to analyze sales data
* Added slicers and a timeline for interactive filtering
* Built an interactive dashboard to explore sales performance

## Excel Skills Demonstrated

* XLOOKUP
* INDEX/MATCH
* IF functions
* Data cleaning and preparation
* PivotTables
* PivotCharts
* Slicers
* Timelines
* Dashboard design
